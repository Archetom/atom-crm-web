# 市场活动功能边界

## 参考行为

以参考站市场活动的名称检索、关联对象筛选、15 条默认分页、详情抽屉、新建/编辑/删除、参与人员、两组图片和公开表单入口为交互参照；不复用其页面状态、旧接口、上传实现、对象字段或权限判断。

## 已实现的受控流程

`GET /api/v1/marketing-activities` 只接收生成类型中的关键词、关联对象与分页，并由服务端复核 `marketing-activities:read`、租户、数据范围和记录可见性。活动 ID 只作为 URL 中的正安全 `activityId`；详情 Drawer 重新读取该 ID，关闭只移除该参数并保留搜索与分页。`GET /api/v1/marketing-activities/configuration-options` 同时发布关联对象目录：每项含稳定 code、显示名称及 `supportsMarketingForm`，并以 `defaultRelatedObjectType` 发布新建默认选择。筛选、标签、编辑和内嵌表单均只消费该目录；目录未到达或失败时关闭筛选及保存，绝不以显示名、URL、缓存或浏览器枚举臆造对象。

新建和编辑分别由 `marketing-activities:write` 和服务端 version 保护。当前契约声明的关联对象为 `CUSTOMER|CONTACT|LEAD`；参与人员和部门只来自同一身份的受限成员/部门目录，浏览器不会展开部门为成员或手输 ID。浏览/提交计数只接受非负安全整数，服务端负责持久化、并发和范围校验。删除始终要求明确确认及服务端详情原始 version。

活动详情把图片分为 `COVER` 与 `DETAIL` 两个独立组。每组至多九张 PNG/JPEG；上传使用服务端受控附件意图，只有经过安全检查并发布的文件可列出或以认证 Blob 下载。撤回需要当前附件 version，所有上传、状态、可见性和数量并发由服务端复核。

活动可以关联已有营销表单；只有服务端回显已启用表单的公开标识时，详情才显示公开链接。新建活动仅在当前关联对象由目录声明 `supportsMarketingForm`、且调用者拥有 `marketing-forms:write` 时显示“创建采集表单”。当前服务端对 `CUSTOMER` 与 `LEAD` 发布该能力：页面只消费相同目标的服务端字段目录，POST 将生成的 `marketingForm` 连同活动一次提交，服务端在同一事务中创建一份未启用表单并关联；`CONTACT` 不发布该能力，编辑请求也不携带内嵌表单。营销表单自身在 `/marketing/forms` 中以独立、版本化流程调整显示细节并启用公开访问，公开页不加载内部身份、导航或授权数据。

## 仍待后端契约的差异

参考站把关联对象、公开字段选择和活动保存放在同一表单：默认客户，切换到线索时字段勾选目录随对象替换，当前发布字段默认全选。参考页的对象目录还可能含租户配置对象；当前租户未显示联系人。本地已经以服务端目录对齐客户/线索默认与字段目录、同目标原子表单创建及当前页原子批量删除；不能借此为未发布的联系人或扩展对象猜测字段目录、所有者、公开提交归属或对象映射。字段逐项显示名称、帮助文字、占位符以及更多布局调整仍在创建后的营销表单编辑器完成；空列表中其余批量菜单尚未可观察，不能猜测实现。
