# 我的待办功能边界

`/worklist` 是不由服务端 navigation 增加菜单项的内部工作台入口；只在当前授权中明确包含
`worklist:read` 时，顶栏“工具与设置”会提供进入入口。日期是唯一的 URL 可恢复状态；默认当天，用户
选择其他日期时以 `date=YYYY-MM-DD` 恢复。服务端返回的 cursor 经过 Base64 编码，包含来源推进位置，
因此只保留在当前身份隔离的 TanStack Query 无限查询缓存，绝不写入 URL、持久化存储或日志。

`GET /api/v1/worklist` 的 OpenAPI 成功响应目前为泛型对象。运行时严格收窄为固定的九类 kind、来源 ID、
非负来源版本、主体 ID/类型、到期时间、摘要和可选下一页 cursor；任意条目或 cursor 不符合窄投影时整页失败关闭。
摘要与到期时间来自服务端当前权限、字段策略和数据范围裁决，页面不根据主体 ID、当前成员、缓存或本地日期补充业务信息。

单项“确认”只提交同一服务端条目的 `kind`、`sourceId`、`sourceVersion`、`dueTime` 与当前日期。类别“确认全部”
必须先经过明确二次确认，仅提交 `kind + date`，由服务端重新扫描、验证当前可见性并原子保存确认回执。两种确认均
不会修改活动、客户、审批、回访或 Work 任务；成功后只失效同一身份、同一日期的工作台缓存。409 与其他错误绝不自动重试。
